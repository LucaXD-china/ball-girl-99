# 游戏模式与赛季系统

## 模式分期

### 第一阶段：单机核心验证

**已确认**

- 主线：提供主要俱乐部经验，逐步开放首发阵容身价额度、训练和挂机效率。
- 俱乐部赛季：固定轮次的联赛，提供主要培养资源。
- 杯赛挑战：淘汰赛结构，强调阵容调整和关键比赛。
- 训练赛：消耗行动体力，反复培养当前名单中的球员。

第一阶段验证长期 Box、三套羁绊和文字比赛，不依赖社交系统。

### 第二阶段：异步竞争

- 异步天梯：玩家配置进攻阵容和防守阵容，由服务器模拟。
- 好友约战：使用固定 Seed 或相同规则进行可复现对局。
- 周期杯赛：限定阵营、星级或位置规则，推动不同 Box 使用率。

### 第三阶段：长期社交

- 俱乐部或联盟。
- 合作赛季目标。
- 跨周期排行和阵营主题活动。

第三阶段只在异步比赛稳定后进入设计。

## 主线与俱乐部成长

**已确认**

主线从社区成立全新俱乐部开始。城市原有职业俱乐部已经解散，玩家作为首任
Manager，没有可继承的球员和竞技成绩，需要完成职业准入、组建初始名单，并从
最低职业级别逐步升级。

主线承担新系统教学和长期等级推进。玩家通过主线获得俱乐部经验，提升完整
比赛的首发阵容身价额度、行动体力上限和挂机获取效率。

主线也承担玩家认识足球世界的主要路径。位置与阵型通过比赛和阵容选择介绍；老俱乐部、
球迷组织、教练组、球探、青训、医疗体能、运营、主场和升降级通过具体人物与事件介绍。
这些内容必须改变当前目标、功能开放或俱乐部状态，不能只作为资料库中的百科文本。

主线前段先使用三名御三家和小规模赛事教学角色、位置关系、基础特性与招牌技能；
阵型、完整比赛名单、固定注册身价、三人阵营羁绊和常规联赛必须随俱乐部发展逐步开放，
不能在开局要求玩家凑齐完整 11 人阵容。

主线关卡应逐步要求玩家理解位置、阵型、三人羁绊、身价取舍和战术克制，而
不是只用总战力门槛阻止推进。

**原型规则已实现，关卡内容待制作**

主线可以按以下阶段展开：

1. 通过三人训练认识前、中、后，并与御三家保住社区训练场。
2. 通过五人社区赛认识门将和球场宽度，开始寻找新俱乐部的工作人员与球员。
3. 在老球迷与球迷组织帮助下完成注册、主场和参赛资格准备，建立第一套合法名单。
4. 进入 11 人模式，学习标准位置与阵型，在严格身价额度下参加最低级别联赛。
5. 经历积分、升级区和保级压力，恢复城市球迷对新俱乐部的信任。
6. 解决长期主场问题，逐步建立球探、青训、医疗体能与运营职能。
7. 进入全国顶级联赛，形成跨多个阵营的成熟阵容，并挑战传统豪门。
8. 获得洲际资格和世界级广告商赞助，让首发阵容身价额度跨越关键台阶。
9. 解锁洲际赛事和异步天梯；身价额度越过实用自由阈值后仍继续累积，记录全球球迷、
   商业规模和玩家荣誉。

旧俱乐部的历史提供城市记忆、球迷情感和理解俱乐部文化的入口。新俱乐部不恢复或
继承旧队荣誉，而是在老球迷与新成员共同参与下建立属于玩家和球娘的新历史。

## 训练赛

**已确认**

- 训练赛消耗行动体力。
- 玩家安排当前已开放赛制的阵容；三人和五人训练沿用小规模位置槽，正式准入后才
  使用完整 11 人阵容。比赛中不设置手动操作。
- 进入阵容的球娘获得完整经验。
- 培养新球员时，玩家需要权衡是否让其占据训练赛首发。
- 已完成的训练赛应支持连续执行或快速结算，避免重复观看低难度比赛。

训练赛主要服务角色追赶和阵容试验，不应成为招募代币或最高级培养材料的稳定
来源。

## 俱乐部赛季

**方向已确认，关卡内容待制作**

一个赛季包含：

1. 赛季目标选择。
2. 常规比赛轮次。
3. 训练和阵容调整窗口。
4. 赛季中期杯赛。
5. 排名结算与升降级。

首次正式赛季要把积分、排名、升级区与降级区作为可理解的俱乐部目标逐步引入。杯赛
通过淘汰制和“一场决定去留”的剧情张力，与联赛的长期积分竞争形成明确区别。赛季
结算除资源外，还要记录俱乐部级别、球迷反应、升级或保级结果及一段可回看的赛季历史。

赛季不能只是一串自动比赛；应通过对手风格和阶段任务要求玩家在比赛前调整
阵容，但首版不加入过度复杂的合同和财务模拟。比赛开始后玩家只观看球娘发挥，
不进行临场操作。

## 关卡风格与 Box 扩张

**提案**

主线、赛季和杯赛关卡都为对手设置一种“主要风格”，只使用阵营策划中的四种
战术母型。赛前预览直接展示：

```text
对手主要风格：稳守终结
推荐应对：破阵创造
可选核心：赤红斗牛 / 桑巴联盟
```

玩家可以调整三人阵营核心；首发中的三个三人羁绊组全部参与软克制，而且允许
重复阵营、重复母型和同属性叠加。玩家既可以用 `3+3+3` 覆盖多种风格，也可以用
同母型的 `6+3` 构型集中针对当前关卡。一个对手即使拥有多套羁绊，也只标记一种主要
风格；次要特点通过球探文字说明，不扩张成复合克制表。

普通主线允许玩家使用三层正确克制，从全国成名阶段开始可以把它作为最强推荐解。
首批每阵营新增三名三星位置球员后，玩家还可以逐步组成 11 人纯阵营首发，形成
三层同名羁绊。单推阵营是可行的高完成度路线，但不会成为主线唯一解。

关卡设计遵守以下边界：

- 正确克制是推荐解，不是准入条件。不得出现“没有某阵营就无法造成伤害”的规则。
- 当前 V4 中，`1/2/3` 层正确克制的镜像胜率增幅为
  `3.38 / 9.15 / 14.67` 个百分点；专精越深，针对越强、其他风格覆盖越少。
- 前期依次教学四种母型，并通过主线赠送、定向招募或可兑换角色，保证玩家能逐步
  组成每种母型至少一套基础三人核心。
- 中期连续关卡应轮换主要风格，鼓励玩家培养第二、第三套可用核心，而不是只提高
  对手总战力。
- 主线中后段支持三层克制，但仍需保留高培养混编加合理阵型等替代解法。
- 高难关卡可以用特殊技能改变常规解法，但必须在赛前球探中明示，且保留至少两种
  可行阵容思路。
- 赛后说明风格对位具体影响了哪些推进、机会和 xG，让玩家能判断换阵是否有效。

这样，扩大 Box 不只带来更多低成本解法，还允许玩家从三人核心逐步扩充为六人和
九人专精阵容。高星主力仍然有价值，但广铺高星不会自动获得三层同属性针对。

六阶段、24 个主线校准模板、四阵型定位和各阶段目标胜率见关卡、阵容与身价成长 V1（历史）。

## 周期规则

周期玩法可以限制：

- 最高星级数量。
- 指定阵营加成。
- 必须使用一定数量的 3 星或 4 星角色。
- 特定阵型或战术。

这类规则用于扩大角色使用面，不能成为永久主线阵容的强制限制。

## 奖励原则

- 主线赛季提供稳定资源。
- 高难杯赛提供稀有但非唯一的培养资源。
- 排名奖励避免让领先玩家持续扩大不可追赶的数值差。
- 训练赛不消耗正式比赛资源，也不提供可刷取的核心产出。
