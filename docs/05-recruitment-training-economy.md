# 招募、培养与经济系统

## 系统目标

**方向已确认**

MVP 不引入真实付费。玩家通过主线、任务、比赛和挂机逐渐积累代币与培养
资源，再决定投入招募、当前阵容培养或新角色追赶。经济系统需要同时支持收集
目标、长期成长和阵容试验，不能让玩家因为培养错误而长期无法更换阵容。

## 资源分类

**提案**

| 资源 | 主要来源 | 主要用途 |
|---|---|---|
| 招募代币 | 赛季、任务、活动 | 抽取球娘 |
| 训练资金 | 比赛、日常任务 | 角色等级与训练室基础消耗 |
| 训练笔记 | 日常、比赛、挂机 | 角色等级训练 |
| 技能卡与同名残页 | 日常商店、每日与每周任务、训练挑战 | 技能配置与确定性升品 |
| 专属升星凭证 | 重复获得同名角色 | 角色升星 |
| 通用研习材料 | 每日与每周任务 | 技能卡升品和回收再利用 |
| 通用升星凭证 | 周期玩法、保底补偿 | 少量替代指定角色重复卡 |
| 球迷规模 | 主线成绩、赛事表现、俱乐部挂机经营 | 提高周边收入和商业吸引力，不直接消费 |
| 俱乐部营收 | 周边经营、比赛日、商业赞助 | 支撑俱乐部规模和可持续首发阵容身价额度 |

正式名称和产出数值待世界观与经济模型确定。

招募代币与培养资源保持分离，避免“所有资源永远只用于抽取”成为唯一正确选择。

## 俱乐部等级

**已确认**

玩家拥有长期提升的俱乐部等级。主线是俱乐部经验的主要来源，升级后提高：

- 完整比赛的首发阵容身价额度。
- 行动体力上限。
- 日常挂机资源的每小时获取效率。
- 后续训练赛和玩法难度的开放范围。

俱乐部等级不直接给比赛属性加成。它通过容纳更高身价的首发和提高养成效率
形成长期成长，避免等级直接压过阵型和角色设计。

## 球迷、周边与商业赞助

**已确认**

首发阵容身价额度来自俱乐部的可持续商业能力，不是随等级凭空增加：

```text
可持续首发阵容身价额度
  = 当前俱乐部基础盘
  + 球迷与周边经营增量
  + 当前商业赞助投入
```

挂机经营会持续增加球迷规模，并根据球迷规模、俱乐部声望和当前商业阶段产生周边
收入。该增长提供平滑的身价额度提升，但每个商业阶段设置合理上限，不能只靠长时间
挂机绕过主线和赛事成绩。

当剧情明确表现俱乐部规模扩大时，必须同步出现新的赞助来源和一次可感知的身价额度
跨台阶。赞助不是抽象的升级按钮，而要在剧情、俱乐部主页和阵容界面中说明“是谁
开始支持球队、为什么愿意投入、这次投入让俱乐部能承担怎样的名单”。

建议的商业成长阶梯：

| 俱乐部阶段 | 主要支持者 | 触发事件 | 身价额度表现 |
|---|---|---|---|
| 社区草创 | 社区死忠球迷捐助 | 保住训练场、成立新俱乐部 | 极小基础盘，只能维持教学与试训阵容 |
| 社区立足 | 社区企业与本地商户 | 获得稳定主场和本地赛事资格 | 首份稳定赞助，小幅跨台阶 |
| 职业起步 | 地区企业和本地广告商 | 完成职业准入、进入正式联赛 | 能承担完整 11 人与少量高星核心 |
| 全国成名 | 全国性广告商与快速增长的周边收入 | 升入高级别联赛、取得标志性成绩 | 明显扩大高星和多羁绊共存空间 |
| 洲际资格 | 世界级广告商 | 获得洲际赛事资格 | 大幅跨台阶，支持接近自由组合的豪门名单 |
| 世界舞台 | 多家世界级合作伙伴与全球球迷市场 | 进入世界俱乐部赛事 | 维持极高但仍有限、可继续成长的身价额度 |

广告商和企业均使用架空身份，不直接引用现实品牌。最高阶段仍保留可持续身价额度，
但应足够宽裕，让当前内容中的绝大多数组合都可实现；未来卡池和世界线扩展时，再通过
新的球迷规模、商业合作与剧情里程碑继续提升，而不是切换成永久 `unlimited`。

### 实用自由阈值与荣誉累积

**已确认**

首发阵容身价额度始终保留一个可见、有限且只增不减的数值。当它已经高于当前版本
“任意合法 11 人”的最高身价需求时，玩家体验上等同于自由组队，但系统不隐藏、
不封顶，也不切换成无穷值。

超过实用自由阈值后，新增身价额度承担三项作用：

1. 记录俱乐部从社区球队成长为世界豪门的商业规模。
2. 把冠军、洲际资格、世界赛事成绩和重要赞助永久沉淀为玩家荣誉。
3. 为未来新增角色、更高商业阶段和更昂贵阵容预留真实容量。

因此即使当前所有阵容都能上场，球迷增长、周边收入、奖杯和新赞助仍会让身价额度
继续累积。阵容页默认只展示第一行；俱乐部档案或策划调试页可以展开其余阈值：

```text
本场首发总身价：€346m / €460m
当前内容实用自由阈值：€520m
全 6 星战略预留阈值：€660m
俱乐部历史最高身价额度：€710m
```

当前内容实用自由阈值由运行 Box 和合法位置动态计算；按 `market-value-v1`，
当前 88 人 Box 仍为 `€520m`。`€660m` 是 11 名 6 星的理论身价，只作为未来卡池的战略
预留，不冒充当前内容需求。两种阈值都不是新的硬上限。历史最高身价额度属于永久
俱乐部档案，不随赛季重置；具体名称
可在世界观确定后改为“商业规模”“豪门指数”或其他更有代入感的表达。

## 固定注册身价与首发阵容身价额度

**已确认**

- 身价额度限制 11 人组成的完整比赛阵容。
- 获得和持有角色不受俱乐部等级限制。
- 球娘固定注册身价不随角色等级、技能配置或升星变化。
- 高星角色拥有不可逾越的个体能力优势，同时通常占用更多身价额度。
- 低星通过身价效率、位置补充、阵营羁绊和专项技能保留使用价值。

固定注册身价不是日常消耗，不会在每场比赛后扣除；它是构建首发时使用的容量。
它也不等同于俱乐部真实支付的转会费或年薪，而是用现实足球熟悉的欧元身价尺度
表达阵容豪华程度。

身价额度始终存在，但会随球迷、周边收入、俱乐部规模和赞助等级持续提高。高等级
俱乐部的空间应越过当前版本的实用自由阈值，允许玩家自由尝试任意合法 11 人组合；
“仍然有限”表达的是俱乐部规模和玩家荣誉始终有可持续累积的数字，而不是在终局
继续强迫玩家大量使用低星。

球娘升级、技能配置和升星仍不提高角色固定注册身价。玩家培养深度与俱乐部成长
通常会同步推进，但身价额度由俱乐部成长解锁，不因单张角色升级而反向收紧。

若未来某些周期挑战需要“低身价阵容”“限定星级”等构筑题，应作为独立玩法规则明确
展示，不能与俱乐部正常商业能力混淆。

**V1 数值原型，待体验校准**

| 星级 | `market-value-v1` 固定注册身价 |
|---|---:|
| 3 星 | `€2m` |
| 4 星 | `€8m` |
| 5 星 | `€25m` |
| 6 星 | `€60m` |

该表使用非线性价差表现高星稀缺溢价，同时让三星成为前中期位置骨架和纯阵营补位。
首发阵容身价额度的阶段原型为 `€60–80m → €100–140m → €180–240m →
€300–380m → €460–540m → €660m+`。后续通过阵容模拟确认跨星级收益和低星使用率。

完整阶段数值、当前卡池 `€520m` 实用自由阈值与 `€660m` 战略预留阈值见关卡、阵容与身价
成长 V1（历史）。

## 行动体力

**已确认**

行动体力是账号级资源，进入训练赛等可重复日常玩法时消耗，用于控制重复获取
养成资源的速度。首版比赛不模拟球员体力衰减，也不设置体力管理或自动换人。

## 招募

**V1 原型已实现，数值待校准**

招募系统同时承担球星卡收藏文化的入口。正式主线中，玩家应先通过御三家共同经历的
比赛获得一张有明确故事来源的首战纪念卡，再开放常规阵营卡包。第一次卡片体验先说明
卡片为何记录这名球员和这一场比赛，随后才介绍基础卡、稀有版本、阵营定向与保底。

同一名球娘是唯一可培养的球员实体，但可以拥有基础卡、赛季卡或纪念卡等不同版本。
卡片版本记录能力层级、赛季主题或重要足球时刻，不能在没有明确存档迁移和玩法规则时
悄悄生成第二个同名可上场实体。完整的收藏引导见
[足球体验与渐进引导 V1](17-football-discovery-and-guidance.md)。

- 阵营十连包基础概率为三星 `40%`、四星 `50%`、五星 `8%`、六星 `2%`。
- 首次十连至少出现一名五星或六星球员。
- 所有阵营卡包共享六星软保底；连续 50 抽未出六星后，每抽增加 2 个百分点，出六星后复位。
- 阵营定向包只改变同星级候选球员范围，不额外改变星级概率。
- 详细卡池边界、演出、存档与实现状态见[抽卡系统：阵营卡包、概率与角色演出 V1](15-faction-pack-market.md)。

活动池、六星归属规则和通用升星凭证的兑换边界仍待定。

约束：

- 必须公开概率和保底进度。
- 新玩家应能通过确定性路径获得一套可触发三套羁绊的基础阵容。
- 阵营偏科不能让抽到同阵营角色成为无法上场的坏结果。
- 每张进入收藏的卡应连接角色位置、核心特点、使用建议、可观察的比赛行为，以及对应
  的故事、赛季或收藏主题；抽取结果不能只有星级和数值。

## 培养

**方向已确认，数值提案见独立文档**

培养拆为三条长期轴：训练室提升角色等级和基础能力；白、蓝、紫、金、彩技能提供
可替换构筑；重复角色用于升星并强化固有天赋。传统装备系统不进入当前设计。

训练室只消耗训练资金和训练材料，不训练技能。参加比赛可以提供少量训练材料，但
不会绕过训练室直接累积角色经验。技能卡通过日常商店、任务、训练挑战和赛季目标
确定性获取、升品；常规白蓝技能和基础研习材料不是稀缺付费资源。

完整规则见[球员养成与技能配置系统 V2](16-player-development-and-skill-loadout.md)。

## 挂机资源

**已确认**

日常挂机提供稳定的基础培养资源，获取效率随俱乐部等级和主线进度提高。挂机
用于降低日常操作负担，不替代主线、杯赛和阵容试验。

**提案**

- 主要产出训练资金和基础经验资源。
- 设置累计领取上限，避免无限离线积累。
- 招募代币、金彩技能核心和通用升星凭证主要来自主动玩法。

## 重复角色

**已确认**

重复角色不生成第二个可上场实体。首次获得后再次抽到同一角色，会保留持有张数并
自动提升该角色的升星阶段，不需要玩家额外确认或操作。

御三家不进入任何招募池，因此没有重复角色、碎片或定向兑换产出。留下的基石角色
的升星凭证与其他成长资源应通过主线和常规培养系统获得；离队二人不提供可绕过剧情
重逢的获取路径。

## 低星长期价值

**已确认**

3 星和 4 星不能通过培养追平同位置高星，其长期价值来自：

- 更低固定注册身价和培养成本。
- 明确的固有天赋和紫色专项技能槽。
- 更容易获得突破材料。
- 阵营和位置补位能力。
- 在正确阵型与羁绊中提供更高的首发身价效率。

身价额度极度宽裕后，低星不再依靠“更便宜”保证终局首发位置；其终局价值主要
转为专项技能、稀缺位置、阵营补位、培养成本较低以及限定挑战。顶级俱乐部可以
承担接近全高星的阵容，这是球迷与商业成长的长期回报。
