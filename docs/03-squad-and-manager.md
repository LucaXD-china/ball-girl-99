# 阵容与 Manager 系统

## 首发阵容

**已确认**

每场比赛由 11 名首发球娘组成。阵容需要同时满足阵型位置和角色可用位置，
并允许构成三层可重复的三人阵营羁绊与两个未成组位置。同阵营每满三人增加一层，
同名、同母型和同属性效果均可叠加。

完整 11 人阵容仅在俱乐部取得正式比赛资格后开放。主线前段的小规模赛事使用
独立的赛制和名单规则，不要求凑齐完整阵型，也不提前计算完整比赛的身价额度或
三套羁绊。具体展开见[开局与主线展开](08-onboarding-and-progression.md)。

## 完整比赛阵容

**已确认**

每场比赛只提交 11 人首发，不设置替补名单，也不在比赛过程中换人。俱乐部首发
阵容身价额度只作用于这 11 人；未进入本场阵容的 Box 角色不占用额度。

角色使用以 `€m` 表示的固定注册身价，主要表达星级强度、版本稀缺度和角色定位。
球娘等级、技能配置、固有天赋强化和升星进度不会增加固定注册身价。

身价额度来自俱乐部当前可持续商业能力。球迷规模、周边收入和俱乐部等级提供平滑
增长，关键剧情中的新赞助提供跨台阶增长。最高发展阶段仍保留并继续累积具体欧元
数值，但应超过当前版本任意合法 11 人的最高需求，实际体验接近自由组队；高星与
三套羁绊同时成立是长期经营成果。

## 阵型

**已确认，具体数值待校准**

首版支持四种特点鲜明的阵型。阵型与阵营是两条独立的 Manager 建队决策轴：
阵营决定羁绊与软克制，阵型决定位置需求、机会类型与比赛阶段优劣。

| 阵型 | 主要收益 | 明确代价 |
|---|---|---|
| 4-3-3 | 边路推进、前场宽度、三前锋持续施压 | 中路人数较少，边后卫身后容易被转换利用 |
| 4-2-3-1 | 双后腰保护、前腰组织、攻守平衡 | 单前锋终结依赖核心，禁区持续占位较少 |
| 4-4-2 | 双前锋、传中、二点球与直接压迫 | 中路创造依赖边路或前锋回撤 |
| 3-5-2 | 中场人数、禁区保护、双前锋联动 | 两翼空间风险高，依赖翼卫适配和往返能力 |

角色在主位置出场时发挥完整能力；使用可兼任位置时受到较小熟练度影响；完全
不适配的位置不能直接上场。

首版不设置第二张显式阵型克制表。阵型的收益与代价落到推进、机会和防守事件，
形成比阵营三层克制更轻的软对位，并在赛前说明和赛后报告中可见。

十一人模式也是玩家第一次系统认识标准位置与阵型的阶段。阵型说明除收益和代价外，
必须解释球队如何推进、如何创造机会，以及失去球权后由哪些位置保护危险区域；一键
推荐要给出位置适配与阵型职责理由，不能只返回总能力最高的名单。完整引导契约见
[足球体验与渐进引导 V1](17-football-discovery-and-guidance.md)。

## Manager 决策

**已确认**

玩家的主要操作发生在赛前：

- 选择阵型。
- 安排 11 人首发。
- 选择整体战术：均衡、控球、反击、高压或低位防守。
- 指定一项重点指令。
- 选择定位球和关键球员职责。

重点指令示例：

- 围绕某名球娘组织进攻。
- 主攻左路或右路。
- 优先争取定位球。
- 开局高压。
- 领先后收紧阵型。

这些选择需要改变技能触发条件和比赛事件分布，而不是只改变一项不可见数值。

## 比赛过程

**已确认**

比赛开始后玩家不进行操作，不设置换人顺序、条件换人或体力管理。首发阵容在
整场比赛中保持不变，比赛引擎不模拟体力衰减或自动换人。

比赛可以产出训练材料，但不会绕过训练室直接提升角色等级。玩家若要快速培养新球员，
需要把训练材料和训练槽位投入该角色，不必为了刷经验强迫她进入正式比赛阵容。

阵营羁绊由 11 人阵容在开场时确定，并在整场比赛中保持不变。

## 阵容校验

进入比赛前必须检查：

- 首发人数为 11。
- 每名角色唯一。
- 每个阵型位置都有可用角色。
- 11 人固定注册身价总和不超过当前由俱乐部商业能力支撑的首发阵容身价额度。
- 阵营羁绊的阵营、层数、战术母型和软克制结果明确展示。
- 战术和重点指令已选择或使用默认值。
- 每名球员的技能卡没有被本阵容中的其他球员重复占用，且位置和槽位品质限制合法。
- 阵容战力展示能够拆分基础能力、固有天赋、配置技能和羁绊贡献。
