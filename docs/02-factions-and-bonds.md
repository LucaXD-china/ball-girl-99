# 阵营与羁绊系统

## 阵营原则

**已确认**

阵营的内部来源是原型球员国籍；玩家侧使用具有足球文化辨识度的虚构称号，
不直接显示现实国家名称。虚构称号不是现实政治实体。

| 内部来源 | 公开阵营 | 主要风格 | 6 星侧重 |
|---|---|---|---|
| England | 雾都王庭 | 长传、制空、强度与后插上 | ST |
| France | 高卢鸢尾 | 速度、单点爆破与全面身体素质 | ST |
| Germany | 钢铁引擎 | 战术纪律、控制与高位压迫 | CDM |
| Spain | 赤红斗牛 | 控球、短传和技术边锋 | CM |
| Brazil | 桑巴联盟 | 盘带、创造力和边路突击 | LW |
| Argentina | 潘帕斯银辉 | 镇定、禁区终结和比赛韧性 | CAM |
| Japan | 樱华连结 | 连续接应、无球穿插和整体提速 | CM |
| Italy | 苍蓝堡垒 | 防守组织、门将和快速转换 | GK |

### 备选阵营：葡萄牙大航海团

**已确认：备选方案，不进入当前运行池**

葡萄牙原型阵营 `cape_voyagers`（大航海团）已由樱华连结替换。它保留“技术中场、
纵向冲击和禁区终结”的完整设计以及原 8 人候选名单，供未来赛季扩阵或阵营轮换
评估；当前 `launch-roster-v1`、`expanded-roster-v1`、羁绊、软克制和卡面生产均不
读取该阵营。

备选数据位于 `data/characters/alternate-factions-v1.json`，并固定
`status=reserve_proposal`、`runtime_pool=false`、`replaced_by=sakura_link`。
在显式提升版本和重新校准前，不得把大航海团角色混入当前 88 人 Box。

## 位置偏科

**已确认**

阵营卡池不平均分配各位置，而是通过高星角色和角色数量表现足球特点。

- 苍蓝堡垒拥有更多高星门将、后卫和防守型中场。
- 赤红斗牛的最高稀有度和主要深度集中在中场。
- 高卢鸢尾和桑巴联盟更容易获得高星前锋与边锋。
- 钢铁引擎强调防守中场、出球后卫、门将和整体纪律。

偏科不能造成某阵营完全无法组成三人羁绊，但允许其缺少部分关键位置，迫使
玩家混编其他阵营或使用自由人。

## 三人羁绊

### 当前杯赛简化规则

《冠军联赛99日》使用独立的单层版本：同阵营首发达到 3 人即激活，6 人和 9 人不再叠层；
每个阵营只修改进攻、防守、控球或进球概率中的一项能力。具体映射与数值以
[杯赛数值子系统 V1](20-tournament-numerical-system.md#杯赛单层阵营羁绊)为准。下文的重复羁绊、
机会类型和战术母型克制属于长期 Manager / Python V4 设计，不代表当前杯赛运行规则。

**已确认**

同阵营每满三名首发球娘激活一层阵营羁绊。理论上的 11 人完整构型为：

```text
三人羁绊组 × 3
未成组位置 × 2
```

即 `3 + 3 + 3 + 1 + 1`。

三个三人组可以来自不同阵营，也可以重复：

```text
广度组合：阵营 A × 3 + 阵营 B × 3 + 阵营 C × 3 + 任意 × 2
混合针对：阵营 A × 6 + 阵营 B × 3 + 任意 × 2
极限针对：同母型阵营 A × 6 + 同母型阵营 B × 3 + 任意 × 2
```

因此同一阵营每满三人增加一层同名羁绊。基础 64 人卡池中每阵营只有八名角色，
实际最多形成两层同名羁绊；第三层同属性可以由同一战术母型的另一个阵营补足。
首批位置完善扩充已为每阵营新增三名三星，使每阵营达到 11 人，能够组成纯阵营
首发并激活三层同名羁绊。最后两个未成组位置仍正常发挥个人技能，不计入也不破坏
已经激活的羁绊。

**原型实现，待长期校准**

- 首版不设置 2/4/6 人阶梯，避免阵容规则过于硬核。
- 羁绊提供战术倾向或条件能力，不直接给全属性百分比。
- 多层羁绊落到同一属性或比赛挂点时直接叠加，不因同名、同阵营或同母型而失效。

当前 V4 原型已经为八个阵营配置不同组合：

| 阵营 | 羁绊 | 主要加强方向 |
|---|---|---|
| 雾都王庭 | 王庭制空 | 长传创造、角球形成与制空质量 |
| 高卢鸢尾 | 疾速突围 | 转换进攻形成率与纵深机会质量 |
| 钢铁引擎 | 压迫齿轮 | 控球稳定与整体压迫防守 |
| 赤红斗牛 | 连续传控 | 连续控球、阵地战创造与渗透 |
| 桑巴联盟 | 边线桑巴 | 边路一对一、突破形成与射门空间 |
| 潘帕斯银辉 | 银辉定音 | 镇定和关键区域终结转化 |
| 樱华连结 | 樱华连携 | 连续接应、无球穿插与转换推进 |
| 苍蓝堡垒 | 苍蓝反击 | 禁区防守、门将保护与守转攻 |

各羁绊的具体比赛挂点、原型数值和 `0/1/2/3` 层对照方法见文字比赛 V4 规则与校准（历史）。

## 四种战术母型与软克制

**已确认，原型已校准**

八个阵营不建立难以记忆的 `8 × 8` 克制表，而是归入四种战术母型。每个母型由
两个阵营以不同方式实现，阵营原有羁绊仍负责表现具体特色。

| 战术母型 | 所含阵营 | 两种实现方式 |
|---|---|---|
| 破阵创造 | 赤红斗牛、桑巴联盟 | 赤红通过连续传控和中路渗透拆解阵型；桑巴通过边路一对一拉开缺口 |
| 压迫争夺 | 钢铁引擎、雾都王庭 | 钢铁通过整体压迫和拦截破坏组织；雾都通过对抗、制空和二点争夺打断节奏 |
| 纵深冲击 | 高卢鸢尾、樱华连结 | 高卢依靠个人速度和快速转换攻击身后；樱华通过多点接应、第三人跑动和边中换位穿过压迫 |
| 稳守终结 | 苍蓝堡垒、潘帕斯银辉 | 苍蓝依靠禁区组织和门将降低机会质量；潘帕斯接受低回合比赛并用镇定终结决定胜负 |

克制关系只保留一个闭环：

```text
压迫争夺 → 破阵创造 → 稳守终结 → 纵深冲击 → 压迫争夺
```

| 优势方 | 被针对方 | 足球层面的原因 |
|---|---|---|
| 压迫争夺 | 破阵创造 | 在组织和推进阶段增加持球压力，使连续传递或单点创造更难完整展开 |
| 破阵创造 | 稳守终结 | 通过转移、连续配合或边路突破拉动低位阵型，获得更好的禁区入口 |
| 稳守终结 | 纵深冲击 | 主动压缩身后空间、保护禁区，降低快速推进直接形成高质量射门的概率 |
| 纵深冲击 | 压迫争夺 | 越过第一道压迫或直接攻击高位防线身后，将对手的前压转化为空间 |

这里的“克制”是条件优势，不是阵营伤害，也不直接增加全队总属性：

- 三个已激活的羁绊层全部参与本场风格判定，不需要从中三选一。
- 同名羁绊、同一母型的两个阵营，以及最终落到同一比赛属性的效果均可叠加。
  例如 `赤红 × 6 + 桑巴 × 3` 会形成三层破阵创造，集中针对稳守终结。
- 叠加发生在具体比赛挂点：三层破阵可以连续提高拉开防线、突破低位和创造禁区入口
  的能力，而不是获得抽象的“对某阵营伤害 +30%”。
- `1/2/3` 层克制必须形成明显分档。V4 的 500 Seed、主客镜像结果为相对关闭克制
  提高 `3.38 / 9.15 / 14.67` 个胜率百分点，让九人专精构型能够以覆盖面换取强针对性。
- 同属性叠加不设置额外的同名衰减，但仍服从比赛阶段本身的合法概率边界，不能把
  丢球、创造机会或进球变成必然事件。
- 没有正确克制时仍可依靠更强球员、合理阵型或技能组合获胜，主线不得把特定阵营
  设置成唯一解。

这套结构同时支持广度和专精：`3+3+3` 可以覆盖三种不同能力，也可以把两层或三层
压到同一属性上极限针对。扩充 Box 的价值既包括为四种母型各培养一套三人核心，也
包括逐步凑出六人同名、九人同属性和十一人纯阵营的高强度专精阵容。纯阵营单推是
可行的高完成度路线，但普通主线始终保留混编、高培养加合理阵型等其他解法。

## 待验证

- 三人羁绊的收益是否足以影响配队，又不会压过单个角色能力。
- 四种母型是否能让玩家在不查看说明的情况下说出克制闭环。
- `1/2/3` 层同属性叠加是否形成清晰梯度，并分别落在预定胜率增幅区间。

羁绊按 11 人阵容在比赛开始时锁定，并在整场比赛中保持不变。V4 提供同阵容、
同对手、同 Seed 的 `0/1/2/3` 层羁绊批量对照，以及重复计层、同属性叠加、
四关系主客镜像和高星对照。具体结果见文字比赛 V4 规则与校准（历史）。
