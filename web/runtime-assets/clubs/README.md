# 玩家俱乐部队徽

`player-club-crest-v1.svg` 是赛事特别篇中玩家新俱乐部的正式 V1 队徽，不是阵营徽章，
也不复制任何现实俱乐部标志。视觉结构参考传统英格兰俱乐部圆章：圆形主体、上下绶带、
中央纵向徽记与左右对称节点；真实名称、帆船、红魔和商标细节均不使用。

- 视觉主题：红金星焰。
- 核心图腾：星焰足球、中央小盾、双侧花结。
- 固定配色：竞技红、深酒红、冠军金、象牙白。
- 区分方式：玩家队使用圆章与上下绶带，对手队使用纵向盾徽，在签表中能快速识别我方。
- 文字边界：只使用赛事品牌 `BALL GIRL / 99 DAYS`，不写死玩家输入的球队名称。

如果未来增加队徽自定义，应把本图保留为默认正式方案；颜色、图腾和盾形选择属于新的
产品功能，不应通过修改这一个文件来模拟。
