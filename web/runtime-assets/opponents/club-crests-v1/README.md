# 对手俱乐部队徽 V1 视觉锚点

本目录是 99 日赛事特别篇的原创运行时队徽源文件。所有队徽使用 `120 × 136` 画布、
盾形外轮廓和高对比中心图腾，以保持同一赛事体系；中心图腾、主色和内部构图必须保持
差异，不能在后续重绘中退化为只换色的同一模板。

修改前必须同时复核：

- `web/src/data/tournamentJourney.ts`：玩家可见名称、文化阵营与运行时资源路径。
