# 角色卡面清单

本目录保存《冠军联赛99日》的卡面组合契约与生成清单。运行时卡面由统一 Manifest 解析，
本目录的 JSON 是卡面身份、分层契约与生成提示的真源。

- `launch-card-art-v1.json`：64 张首发卡面的生成与验收清单。
- `faction-three-star-card-art-v1.json`：八阵营各 3 人、合计 24 张的三星扩充清单。
- `founder-card-art-v1.json`：3 张御三家 5 星剧情卡（分层契约：透明角色母版、纯背景、
  独立画框、五星标记、位置徽章、身份 UI 彼此独立）。
- `opponent-card-art-v1.json`：30 名对手核心球员正式卡面（26 张五星 + 4 张六星）。
- `rarity-demo-card-art-v1.json`：3/4/6 星分层样板。
- `card-composition-system-v1.json`：四档星级共享的 11 个有序插槽契约。
- `five-star-reveal-animation-v1.json`、`six-star-summon-animation-v1.json`、
  `recruit-reveal-language-v1.json`：抽卡/揭示演出清单。

## 卡面规则

- 卡面严格遵守 `rarity-study-v2` 四档模板，不自行增加签名或额外装饰。
- 3 星 `BASE`：英文排版全名，无签名。
- 4 星 `TACTIC`：英文排版全名，无签名。
- 5 星：英文排版全名 + 位置 + 英文阵营名，无主题、无角标、无签名。
- 6 星 `FLAGSHIP`：英文亲笔签名 + 英文排版全名。
- 中文短名用于球员档案、Box、阵容、比赛播报和玩家交流；详细档案再显示中文全名。
- 英文虚构姓名作为卡面排版名；只有 6 星把英文名的一部分用于虚构亲笔签名。
- 真实能力原型、来源 ID、现实国籍和俱乐部不得进入生成提示或卡面。
- 任何等级的卡面都不显示技能名、技能图标、触发条件或效果；这些信息只进入球员更衣室详情。

## 边界

御三家是唯一剧情角色，只能通过序章选择与后续剧情关系获得，永不进入招募卡池，也不得再作为
卡池概率、抽卡动效或稀有度对比 Demo 的样板。高分辨率卡面 PNG 位于被 Git 忽略的作者母版
工作区，不进入本仓库；本仓库只版本化清单与运行时 WebP/PNG 发布物。
